Why reweighting keeps shortest paths intact

For any path p from u to v, the h terms along the path cancel in pairs, so w′(p) = w(p) + h(u) − h(v). Every u-to-v path shifts by the same constant, so the cheapest one stays the cheapest. Bellman-Ford’s potentials satisfy h(v) ≤ h(u) + w(u,v), which makes every w′ ≥ 0 and lets Dijkstra run safely.
